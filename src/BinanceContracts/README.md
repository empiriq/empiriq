Binance Contracts
===

This package provides strongly-typed **request**, **response**, and **event** objects for the Binance API.  
It helps you work with Binance endpoints in a safe and predictable way.

## Supported Contracts

- [ ] `Derivatives/FuturesAlgo`
- [x] [`Derivatives/FuturesCoinM`](../../src/BinanceContracts/Derivatives/FuturesCoinM)
- [x] [`Derivatives/FuturesUsdM`](../../src/BinanceContracts/Derivatives/FuturesUsdM)
- [ ] `Derivatives/Options`
- [ ] `Spot/Margin`
- [x] [`Spot/Spot`](../../src/BinanceContracts/Spot/Spot)

## Installation

Install via [Composer](https://getcomposer.org/):

```bash
composer require empiriq/binance-contracts
```
